# Matador

Matador is a free, open-source AI trading copilot for retail traders. It
runs locally, keeps its state on your machine, and is designed to work with
the AI agent and market-data providers you choose.

Matador combines market data, explicit strategy rules, persistent memory,
and AI judgment to help form plans, monitor meaningful conditions, and
review outcomes honestly. It advises; the trader decides.

The current reference setup uses Claude and Alpaca while the core workflow
is being proven. The longer-term direction is out-of-the-box configuration
for multiple agents and data sources, with recommended setups, guides, and
templates.

Matador itself has no subscription, hosted account, or required cloud
service. External AI and data providers may have their own costs.

Read more in [Project vision](docs/vision.md).
